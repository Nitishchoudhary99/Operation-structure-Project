Frequently asked questions

Is it real double-entry accounting?

Yes. Every document posts balanced debits and credits to a chart of accounts; reports come from the ledger.

Can my CA use Tally?

Yes. Export a Tally XML for any period and import it into Tally Prime.

Can I take my data out?

Yes. Download a full backup as a file or a readable Excel workbook any time.

Does it handle GST input credit?

Yes. Input credit from purchase bills is tracked and set against output tax in the GST summary.
